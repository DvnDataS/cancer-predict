# 🩺 Breast Cancer Diagnosis Predictor

A machine learning-based web application to classify breast tumors as **benign or malignant** using cell nuclei measurements.

Built with **Python, Scikit-learn, and Streamlit** as a **data science portfolio project** focused on medical prediction.

---

## 🚀 Features

- Interactive input (sidebar sliders)  
- Real-time prediction (**Benign / Malignant**)  
- Probability output  
- Radar chart visualization  

---

## 🧠 Model

- Logistic Regression  
- StandardScaler (feature scaling)  
- Train-test split (80/20)  

---

## 🛠 Tech Stack

Python • Streamlit • Scikit-learn • Pandas • NumPy • Plotly  

---

## ⚙️ Run Locally

```bash
conda create -n breast-cancer-diagnosis python=3.10
conda activate breast-cancer-diagnosis
pip install -r requirements.txt
python model/main.py
streamlit run app/main.py

📊 Dataset
Breast Cancer Wisconsin (Diagnostic) Dataset (Kaggle)
